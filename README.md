# Computer Vision Projects

Welcome to my **Computer Vision Projects Repository!**

This repository is a collection of practical projects built using **Python, Computer Vision, Deep Learning, and AI technologies**. It focuses on developing real-time intelligent systems that can understand visual information, detect objects, track movements, and interact with users through computer vision.

Each project explores different computer vision techniques, combining pretrained models and custom implementations to build interactive applications.

---

## Projects

### 01. Real-Time Object Detection and Tracking

**Overview:**

A real-time computer vision system designed to detect and track multiple objects from live video streams using a webcam or video input.

**Key Features:**
- Detects multiple objects in real-time using a pretrained YOLO model.
- Identifies objects and displays their corresponding class labels.
- Tracks detected objects across consecutive video frames.
- Displays bounding boxes and tracking information.
- Processes live camera input using OpenCV.

**Technologies:** Python, OpenCV, YOLO, Computer Vision, Deep Learning.

---

### 02. Artificial Magic System – Mystic Motion

**Overview:**

An interactive, gesture-controlled visual effects system inspired by magical abilities and visual effects from Marvel movies.

The system uses real-time hand tracking and gesture recognition to allow users to perform different hand movements and trigger magical visual effects directly on the screen.

**Key Features:**
- Real-time hand tracking using MediaPipe.
- Recognizes hand gestures to trigger different visual effects.
- Implements interactive magic effects inspired by Marvel characters.
- Uses OpenCV for live camera processing and visual rendering.
- Supports multiple character-inspired effects, including Doctor Strange, Scarlet Witch, Agatha, Loki, Thor, Wong, and The Ancient One.
- Enables users to interact with visual effects through hand movements without physical controllers.

**Technologies:** Python, OpenCV, MediaPipe, Computer Vision, Gesture Recognition, Real-Time Video Processing.
